# Analytics and Gradebook

The system answers both **what grade was earned** and **what should the student improve next**.

## Grade Sources
- lesson objective scores
- final reviewed lesson scores
- game grades
- mastery status
- academic year
- completion date/time

## Game Grades
Map Hunt attempts are first-class gradebook records. Earlier versions kept game scores separately; Phase 4 merged them into the academic record.

## Academic Years
The active academic year controls where new grades, game attempts, and assignments are recorded. Switching years does not rewrite historical records.

## Assignments
Admins and authorized parents can assign a module or lesson with a due date and target score. Parents can assign only to children already linked to them.

## Skill Analytics
Examples include Map & Spatial Reasoning, Watershed Reasoning, Transportation Networks, Quantitative Reasoning, Historical Causation, Source Analysis, Economic Reasoning, and Critical Thinking.

Skill scores include evidence counts so one successful item is not silently treated as broad mastery.

## Improvement Recommendations
Recommendations can use:
- lowest lesson scores
- repeated attempts
- game average
- strongest game score
- weakest skill with evidence
- mastered lessons that required multiple attempts

## Usage Statistics
Reports can include activity events, active days, recorded learning time, latest activity, game duration, and attempts. Usage is supporting context, not a substitute for achievement.

## CSV Export
Grade exports support homeschool records, spreadsheet analysis, external gradebooks, year-end archives, and future transcript/report generation.
